# Popup visual system is light-only glass

The toolbar popup uses a light glass stack: a cool-blue canvas, white-ladder elevation, and one accent (`#0866FF`). Dark mode is not an invert of this system; a dark theme would need its own surface ladder. AGENTS.md may still reserve a theme pref, but the spec in `docs/design.md` is light-only.

A second accent, grey hairlines, and shadow-stacked cards were rejected because they collapse the white-ladder hierarchy.
