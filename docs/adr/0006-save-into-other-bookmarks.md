# Save current page into Other Bookmarks

The First slice ＋ button creates a Bookmark with no folder picker (PRD D2). The parent is the browser's Other Bookmarks folder (`folderType === "other"`), looked up from the tree — never a hardcoded id. The Bookmarks Bar was rejected so new saves do not recreate the overflow the 常用 grid exists to replace (PRD P6). Users can move the node in Chrome; Nookmark does not add a picker until Manager.
